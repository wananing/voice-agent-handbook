# toy-bot

儿童故事玩具的语音服务端。设备按住按钮说话，松开后服务端识别、思考、合成、下发。

- 设备协议：WebSocket，JSON 控制消息加二进制 Opus 帧。设备发 `listen_start`、音频帧、`listen_stop`、`abort`；服务端发 `stt`、`tts_start`、音频帧、`tts_stop`。
- ASR：云端流式识别，`listen_stop` 后等最终结果。
- LLM：gpt-4.1-mini，三个工具（天气、提醒、找故事）。
- TTS：云端整段合成。

已知的用户反馈：
1. 按下按钮打断后，玩具有时还会接着说上一句。
2. 问天气要等三四秒才有声音。
3. 打断之后再问"刚才讲到哪了"，玩具说的和孩子听到的对不上。
4. 换了 WiFi 之后玩具就忘了前面讲的故事。
